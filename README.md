# ARMY OF SALVATION Website

A futuristic Boys' Brigade website built with Next.js, TypeScript, Tailwind CSS, Framer Motion, React Hook Form, Zod, and Lucide icons.

## Features

- Futuristic ARMY OF SALVATION visual style
- Responsive navbar and mobile menu
- Hero with uploaded Boys' Brigade photos
- Activities, events, gallery, leadership, join, contact, and member profile pages
- Registration and contact form validation
- Lightbox gallery using real uploaded images
- QR-code-ready member pages: `/members/member-001`, `/members/member-002`, `/members/member-003`

## Run locally

```bash
npm install
npm run dev
```

Open:

```txt
http://localhost:3000
```

## QR Code Use

After deployment, generate QR codes that point to member URLs like:

```txt
https://your-domain.com/members/member-001
```

Replace sample member data in `data/site.ts` when you are ready.
